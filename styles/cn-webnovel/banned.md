# cn-webnovel 禁用表

机器规则在 `style.json`。完整的病因和替换示例见同目录的 `anti-ai-lexicon.md`。

| 类别 | 词 | 上限 |
|---|---|---|
| 程度副词 | 极其、极度、宛如、简直、毫无疑问、分外 | 0 |
| 比喻 | 仿佛（只查叙述） | 0 |
| 廉价转折 | 赫然、悄然、蓦然、不禁、不由得、殊不知、浑然不觉 | 0 |
| 公文腔 | 不仅……更是…… | 0 |
| 表情套话 | 闪过一丝、不易察觉 | 0 |
| 表情套话 | 嘴角勾起 | 每 50 章 1 次 |
| 氛围套话 | 空气中弥漫着 | 0 |

人名前的称号前缀无法可靠地用规则查，由审稿人查。

## 章尾禁用

“这不仅是”“一切才刚刚开始”“命运的齿轮”“他不知道的是”“殊不知”“未完待续”。

书专属的禁用词写进项目的 `extra_banned`，不要改这个文件。
