# 钩子系统

网文读者靠章尾决定要不要翻页。钩子要在写细纲时设计好，不能写完再补。

机器可读的类型表在 `references/hook-types.json`，校验由 `cws check` 的 `hooks` 项完成。

## 类型表

| id | 名称 | 章尾是什么样 | 下章开头怎么接 |
|---|---|---|---|
| `reversal` | 反转 | 刚确立的事实被推翻 | 人物当场的反应或应对 |
| `reveal` | 秘密漏缝 | 秘密露出一角 | 追问或掩盖这一角 |
| `arrival` | 来人 | 不该出现的人出现 | 来人开口或动作 |
| `deadline` | 期限 | 出现倒计时 | 人物开始抢时间 |
| `decision` | 两难 | 必须马上选 | 给出选择 |
| `danger` | 危险逼近 | 停在发生前一刻 | 落下这一击 |
| `message` | 消息 | 短信、电话、文件改变局面 | 读完后的第一个动作 |
| `desire` | 欲望悬停 | 亲密或表白停在临界点 | 接住这一刻，不跳到第二天 |
| `caught` | 撞破 | 被人撞见或差点撞见 | 撞见者的话和圆场 |
| `showdown` | 清算在即 | 对质或打脸已经约定 | 直接进入现场 |
| `question` | 异常 | 发现说不通的细节 | 开始查，或故意不查 |
| `button` | 金句收束 | 一句话让关系换挡 | 顺着余波走 |

## 强度

| 强度 | 含义 | 典型用法 |
|---|---|---|
| 1 | 轻：俏皮收束或小疑问 | Kindle 长篇的过渡章 |
| 2 | 小：下章开头就能解决的小问题 | 日常章 |
| 3 | 中：局面变了 | 大多数连载章 |
| 4 | 强：关系、秘密或安全受到实质威胁 | 付费点、单元末 |
| 5 | 核弹：推翻已知事实 | 卷末、短剧付费集 |

强度不用一直拉满。连续高强度会让读者疲劳，也会让下一次反转没有余地。

## 细纲怎么填

```json
{
  "chapter": 7,
  "hook": {"type": "reveal", "strength": 4, "text": "保险箱里放着她三年前丢的护照", "keywords": ["passport", "safe"]},
  "catch": {"mode": "direct", "keywords": ["door", "Marta"], "note": "接第 6 章结尾的敲门声"}
}
```

| 字段 | 必填 | 含义 |
|---|---|---|
| `hook.type` | 是 | 类型表里的 id |
| `hook.strength` | 是 | 1–5 |
| `hook.text` | 是 | 章尾发生什么 |
| `hook.keywords` | 建议 | 章尾应出现的词，用来确认钩子真的写了 |
| `catch.keywords` | 上一章有钩子时必填 | 本章开头应出现的词 |
| `catch.mode` | | `direct`（默认）或 `delayed` |
| `paywall` | | 付费点章节设为 `true` |
| `final` | | 全书最后一章设为 `true`，不要求钩子 |

## 接钩

默认下一章开头要接住。接住不等于复述：不要把上章结尾再讲一遍，直接写下一个动作。

需要切到别的视角时可以延迟：

```json
{"catch": {"mode": "delayed", "by_chapter": 9, "keywords": ["Marta"], "note": "先切到男主视角，读者更急"}}
```

延迟要写原因，并在平台允许的章数内接上（默认 3 章内）。

## 脚本会查什么

| 情况 | 结果 |
|---|---|
| 细纲缺钩子、类型不在表里、强度不合法 | 错误 |
| 同一类型连续 2 章 | 告警 |
| 同一类型连续 3 章及以上 | 错误 |
| 连续 3 章强度不超过 2 | 告警 |
| 付费点章节强度不够 | 错误 |
| 钩子关键词没有出现在章尾 | 告警 |
| 下章开头没出现 `catch.keywords` | 错误 |
| 章尾命中风格的总结句模式 | 错误 |

连续同型的阈值由平台的 `hooks.max_same_run` 决定。

网文模式默认每章都要钩子（`hooks.required: every_chapter`）。不是连载的项目可以在 `overrides.hooks` 里改成 `unit_end` 或 `none`。

关键词只能证明相关内容出现过，证明不了钩子写得好。钩子是否真的抓人由审稿判断。

## 章尾不要这样写

总结、升华、预告都不算钩子。

| 不算钩子 | 算钩子 |
|---|---|
| 一切才刚刚开始。 | 落款的笔迹她认得。那是她自己的字。 |
| Little did she know, nothing would ever be the same. | Her phone lit up. *I know what’s in your drawer.* |
